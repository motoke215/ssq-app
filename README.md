# 彩票分析工具（手机版）：双色球 + 大乐透
仅供个人历史数据分析与娱乐，不构成任何押注建议。

页面上方两个下拉菜单：先选福彩/体彩，再选彩种。目前已接入：
- 福彩 · 双色球：内置 2003-02-23 至 2026-10-27 全部 3520 期
- 体彩 · 大乐透：内置 2007-05-30 至 2026-10-26 全部 2940 期
（彩种框架是通用的，后续加七乐彩、福彩3D 等只需补数据和参数。）

## 多通道推演（2026-10-28 改造）
- 7 个号码通道：短期热号、长期热号、衰减热度、遗漏回补、邻重号转移、尾数热度、分区轮动。每个通道先拿最近 240 期逐期回测（只用当期之前的数据、无未来函数），明显赢过随机才给权重，否则归零；采纳门槛已收严为「增益 − 1 倍标准误」。
- 结构通道：单双（奇偶）、大小、三区、012 路、和值、跨度、连号的历史分布，给候选组合综合打分，不再只是几条硬性规则。
- 防撞号（可开关，默认开）：避开生日号扎堆（1–31，尤其 1–12）、等差等规律号。中奖概率不变，但中了大奖时与人分钱的期望更低。每注会显示「撞号热度」。
- 页面下方「后台分析与数据」能看到每个通道的回测增益与是否被采用，以及样本外回测对比。必须说明：历史数据无法提升中奖概率，推演的价值在结构合理与防撞号。

## 出号设置（2026-10-28 v4 新增）

- **注数可选**：单式 1 / 3 / 5 / 10 / 20 注，花费随注数自动计算。
- **出号模式**：
  - 严格模式（默认）：通道先过 240 期逐期回测，没赢过随机的权重归零——目前两彩种全部通道都未过关，实际出号是「结构 + 防撞号筛选过的随机」。
  - 历史概率模式（娱乐）：不走回测门槛，7 个通道按历史频率等权给每个号码算概率出号。面板会如实标注「未通过回测、属娱乐风格」。
- **紫微易经（可选勾选，独立模块）**：填公历出生日期与时辰后在本机排盘（农历换算表 1900–2099、安命宫诀、五虎遁、五行局查表、紫微定位查表、天府对称），再以当日农历年月日时按梅花易数起卦（本卦/变卦/动爻）；两边得出的数映射成号码加权，叠加在原算法概率之上，加权了哪些号、出处是什么都会在结果里列明。纯传统文化娱乐推演，无科学预测依据；不勾选时完全不参与出号。

## 开奖数据怎么自动更新
- 仓库里的定时任务 `update-data`（GitHub Actions）每天晚上自动抓取两个彩种的最新开奖，写进 `data-ssq.json` / `data-dlt.json`；抓取脚本是 `scripts/update_data.py`，双源交叉核对，号码对不上就不写入；核对源连不上时会标注单源。
- App 打开时自动联网取最新数据并缓存在手机本地；没网时用缓存或内置数据。
- 抓不到、漏抓时仍可手动导入：页面下方粘贴新几期即可（按当前所选彩种识别）。

## 方式一：最快（不用任何网站）
把 index.html 发到手机，用手机浏览器打开即可，离线可用；联网时会自动补到最新一期。

## 方式二：GitHub Pages（得到一个网址，可“添加到主屏幕”成 App）
1. 新建 GitHub 仓库，上传本文件夹全部文件（含 .github 文件夹）。
2. 仓库 Settings → Pages → Branch 选 main，/(root) → Save。
3. 几分钟后用 https://你的用户名.github.io/仓库名/ 访问；手机浏览器菜单选“添加到主屏幕”。

## 方式三：生成安卓 APK（GitHub Actions 自动打包）
1. 仓库 Actions 页 → build-apk → Run workflow。
2. 完成后在该次运行页面底部 Artifacts 下载 ssq-apk，解压得到 app-debug.apk，安装到安卓手机（需允许安装未知来源应用）。
注：iPhone 不能装 APK，请用方式二。APK 装好后数据同样靠联网自动更新，不用每次重装。
